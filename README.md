# Rua 90 — Arcade Brasileiro

Jogo arcade estático de corrida com identidade visual inspirada nos clássicos brasileiros.

## Executar
Abra `index.html` no navegador ou publique a raiz do repositório em um host estático.

## Controles
- **← / →** ou **A / D**: dirigir
- **Espaço / ↑**: nitro
- **Celular**: controles na tela
- **Esc**: encerrar a corrida

## Recursos
- Cinco carros selecionáveis: Fusca, Opala, Celta, Chevette e Gol G2
- Personalização de cor
- Modos sobrevivência, contra o tempo e trânsito intenso
- Recorde local no navegador
- Layout responsivo para desktop e celular

## Publicação
Compatível com hospedagem estática, sem backend ou variáveis de ambiente.
